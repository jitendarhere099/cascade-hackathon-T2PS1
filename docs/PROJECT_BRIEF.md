# Project Brief

## Project Status
- **Current State**: Environment & Persistent Memory Configured
- **Phase**: Ready for Project Conception / User Requirements Prompt

## Overview
This repository (`cascade-hackathon`) is configured for full-stack rapid application development. It enforces clean architecture, persistent memory, and strict quality verification.

## Core Goals
1. Deliver a polished, responsive, and accessible application suitable for an impactful hackathon demonstration.
2. Build genuine, working functionality with end-to-end user workflows, error handling, and robust data persistence.
3. Maintain zero-secret leaks and verified test coverage throughout the project lifecycle.

## Target Stack
- **Frontend**: Next.js + React (TypeScript), Tailwind CSS, shadcn/ui, Lucide React
- **Backend & Database**: Supabase (PostgreSQL with Row Level Security, Auth, Storage)
- **Testing**: Playwright automated browser tests, TypeScript validation, ESLint
